# STEP 9. 공유 링크 / App Links

작업일: 2026-07-12

## 작업 범위

- 공유 링크: `https://timelink-af0f6.web.app/host/{reservationLinkId}`
- 홈 화면에서 전체 링크 복사 및 Android 공유 시트 제공
- Android App Links intent filter와 외부 URI 처리
- 비로그인 상태에서는 로그인 후 원래 Host 예약 화면으로 이동
- 앱 미설치 시 표시할 Firebase Hosting 랜딩 페이지 구성
- Digital Asset Links 파일 구성

## App Links 인증서

현재 프로젝트에 release 서명이 없어 debug 인증서의 SHA-256 지문만 등록했다. Play Store
배포 전 Play App Signing 인증서 지문을 `hosting/.well-known/assetlinks.json`에 추가해야 한다.

## 배포

외부 Firebase 프로젝트 상태를 변경하는 Hosting 배포는 수행하지 않았다. 실제 링크 검증 전
`firebase deploy --only hosting`을 명시적으로 실행해야 한다.

## 검증 결과

- 변경 전 기준 빌드: `assembleDebug` 성공
- 변경 후 Android 빌드: `assembleDebug` 성공
- Android 단위 테스트: `testDebugUnitTest` 성공
- Firebase Hosting 및 Digital Asset Links JSON 문법 검사: 성공
