# STEP 8. FCM 알림

작업일: 2026-07-12

## 작업 범위

- 로그인 사용자의 FCM 토큰을 `user_private/{uid}`에 저장
- 토큰 갱신 시 Firestore 문서 동기화
- 로그아웃 시 현재 디바이스 토큰 제거
- 예약 신청 시 Host 알림 발송
- 예약 승인/거절 시 Guest 알림 발송
- Android 알림 채널, 권한 요청, 수신 서비스 구성

## 알림 문구

- 예약 신청: `새로운 예약 신청이 도착했습니다.`
- 예약 승인: `예약이 승인되었습니다.`
- 예약 거절: `예약이 거절되었습니다.`

## 서버 발송 구조

Cloud Functions가 `reservations` 문서의 생성 및 상태 변경을 감지한다. Admin SDK로
`user_private/{uid}.fcmToken`을 조회한 뒤 data message를 발송한다. 유효하지 않은 토큰은
`user_private` 문서에서 제거한다.

## 배포 전 확인

이번 STEP에서는 외부 Firebase 프로젝트에 Functions를 배포하지 않는다. 실제 알림 검증 전
Firebase CLI에서 Functions 의존성을 설치하고 명시적으로 배포해야 한다.

## 검증 결과

- 변경 전 기준 빌드: `assembleDebug` 성공
- 변경 후 Android 빌드: `assembleDebug` 성공
- Android 단위 테스트: `testDebugUnitTest` 성공
- Functions 문법 검사: `node --check functions/index.js` 성공
- Functions 실제 배포 및 실기기 수신 테스트: 미수행
